# RUR'U' Cube

## Lancer en local
npm install
npm run dev

## Déployer sur Vercel
1. Pousse ce dossier sur un repo GitHub/GitLab, puis "Import Project" sur vercel.com
   — ou —
2. Avec la CLI : `npx vercel` (puis `npx vercel --prod`)

Vercel détecte automatiquement Vite grâce à vercel.json (build: npm run build, sortie: dist).
